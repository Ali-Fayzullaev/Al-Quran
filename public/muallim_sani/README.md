# Muallim Sani - PDF Файлы и Аудио

Эта папка содержит образовательные материалы для интерактивной системы изучения таджвида "Muallim Sani".

## Структура файлов:

### PDF Уроки:
- `alifba-lesson-1.pdf` - Урок 1: Первые буквы алфавита
- `alifba-lesson-2.pdf` - Урок 2: Продолжение алфавита  
- `alifba-lesson-3.pdf` - Урок 3: Завершение алфавита
- `letters-lesson-1.pdf` - Урок 1: Характеристики букв
- `tanvin-lesson-1.pdf` - Урок 1: Введение в Танвин
- `tashdid-lesson-1.pdf` - Урок 1: Удвоение букв
- `mad-lesson-1.pdf` - Урок 1: Естественное удлинение
- `complete-lesson-1.pdf` - Урок 1: Комплексные правила

### Аудио файлы:
В папке `audio/` должны располагаться:
- `alifba-1.mp3` - Аудио для урока Алифба 1
- `alifba-2.mp3` - Аудио для урока Алифба 2
- `alifba-3.mp3` - Аудио для урока Алифба 3
- И так далее...

## Инструкции по добавлению файлов:

1. Поместите PDF файлы уроков в эту папку
2. Поместите аудио файлы в подпапку `audio/`
3. Убедитесь, что имена файлов соответствуют тем, что указаны в `muallamSaniStore.ts`

## Требования к файлам:

### PDF файлы:
- Формат: PDF
- Размер: до 10MB на файл
- Содержание: структурированные уроки по таджвиду

### Аудио файлы:
- Формат: MP3
- Битрейт: 128kbps или выше
- Качество: четкое произношение для обучения

## Использование:

Файлы автоматически загружаются компонентами системы при переходе к соответствующим урокам. PDF файлы отображаются в интерактивном просмотрщике, а аудио файлы воспроизводятся в аудио плеере.
