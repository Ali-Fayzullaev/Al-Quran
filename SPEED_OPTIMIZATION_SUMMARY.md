# Оптимизация скорости переходов между страницами

## Проблема
При переходе с `/quran` на `/surah/[id]` происходили медленные загрузки без индикатора прогресса.

## Реализованные решения

### 1. 🚀 Индикаторы загрузки
- **SurahPage**: Добавлен красивый анимированный лоадер при загрузке данных суры
- **QuranReader**: Добавлен специализированный индикатор загрузки для компонента чтения Корана
- **NavigationLoader**: Глобальный индикатор прогресса для переходов между страницами

### 2. 📦 Предзагрузка данных
- **usePrefetch.ts**: Создан хук для предзагрузки данных сур при наведении на ссылки
- **OptimizedSurahLink**: Компонент умной ссылки с автоматической предзагрузкой
- **Предзагрузка соседних сур**: QuranReader автоматически загружает соседние суры для быстрой навигации

### 3. 🗄️ Кеширование API
- Добавлен in-memory кеш для API запросов с настраиваемым TTL
- Оптимизирован QueryClient с более агрессивными настройками кеширования
- Улучшена производительность повторных запросов

### 4. 🔗 Оптимизированные ссылки
- Заменены обычные Link на OptimizedSurahLink в ключевых местах:
  - Страница списка сур (`/surahs`)
  - Навигация между сурами (`/surah/[id]`)
  - Включена предзагрузка соседних сур для плавной навигации

### 5. 📊 Мониторинг производительности
- **PerformanceMonitor**: Компонент для отслеживания времени загрузки страниц
- Консольные логи для диагностики медленных загрузок

## Ключевые улучшения

### Скорость загрузки:
- ⚡ Предзагрузка при наведении на ссылки
- 🎯 Умное кеширование API запросов
- 🔄 Оптимизированные настройки React Query

### Пользовательский опыт:
- 🎨 Красивые анимированные индикаторы загрузки
- 📈 Глобальная полоса прогресса для навигации
- 🎯 Мгновенные переходы для кешированных данных

### Техническая оптимизация:
- 📦 Ленивая загрузка компонентов

- 🚀 Предзагрузка критических ресурсов

### Новые файлы:
- `lib/usePrefetch.ts` - Хуки для предзагрузки данных

- `components/NavigationLoader.tsx` - Глобальный индикатор загрузки
