## 🚀 Новые возможности поиска

### 🔤 **Автоматическая транслитерация**

Система автоматически преобразовывает поисковые запросы между:
- **Кириллица ↔ Латиница** 
- **Казахский ↔ Русский ↔ Английский**
- **Узбекский ↔ Русский ↔ Английский**

### 📝 **Примеры поиска**

| Что ввели | Что найдется |
|-----------|-------------|
| `мечеть` | мечеть, mechet, mosque |
| `moscow` | Москва, moscow, мoscow |
| `tashkent` | Ташкент, tashkent, ташкент |
| `almaty` | Алматы, almaty, алматы |
| `kul sharif` | Кул Шариф, Qolşärif, Кул Шариф |

### 🎯 **Умный поиск по частям**

Система находит мечети даже по частичным совпадениям:
- `"кул"` → найдет "Мечеть Кул Шариф"
- `"central"` → найдет все центральные мечети
- `"minor"` → найдет мечеть "Minor" в Ташкенте

### 🔍 **Улучшенный поиск**

```typescript
export function searchMosquesByKeyword(keyword: string): Mosque[] {
  const searchVariations = transliterate(keyword);
  
  return allMosques.filter(mosque => {
    const allTexts = [
      mosque.name,
      mosque.address,
      ...(mosque.alternativeNames || []),
      ...(mosque.services || [])
    ].join(' ').toLowerCase();
    
    return searchVariations.some(variation => 
      allTexts.includes(variation) ||
      // Поиск по отдельным словам
      variation.split(' ').some(word => 
        word.length > 2 && allTexts.includes(word)
      )
    );
  });
}
```
