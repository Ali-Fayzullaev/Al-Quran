# 🕌 Система поиска мечетей для Al-Quran

## 📋 Описание

Комплексная система поиска мечетей, интегрированная в приложение Al-Quran. Позволяет пользователям находить ближайшие мечети с использованием Google Places API, кэширования и fallback системы.

## ✨ Возможности

- 🔍 **Поиск по местоположению** - Использование GPS для поиска ближайших мечетей
- 🏙️ **Поиск по городу** - Поиск мечетей в любом городе мира
- 🔤 **Поиск по ключевым словам** - Поиск известных мечетей по названию
- ⭐ **Фильтрация** - По рейтингу и наличию пятничного намаза
- 🗺️ **Интеграция с картами** - Построение маршрутов через Google Maps
- 💾 **Кэширование** - Локальное кэширование для экономии API запросов
- 🔄 **Fallback система** - Локальная база популярных мечетей при недоступности API

## 🚀 Быстрый старт

### 1. Настройка Google Places API

1. Перейдите в [Google Cloud Console](https://console.cloud.google.com/)
2. Создайте новый проект или выберите существующий
3. Включите Places API:
   - Перейдите в \"APIs & Services\" > \"Library\"
   - Найдите \"Places API\" и включите его
4. Создайте API ключ:
   - Перейдите в \"APIs & Services\" > \"Credentials\"
   - Нажмите \"Create Credentials\" > \"API Key\"
   - Скопируйте созданный ключ

### 2. Настройка переменных окружения

Создайте файл `.env.local` в корне проекта:

```bash
# Google Places API
NEXT_PUBLIC_GOOGLE_PLACES_API_KEY=ваш_google_places_api_ключ_здесь

# Prayer Times API
NEXT_PUBLIC_PRAYER_TIMES_API_URL=https://api.aladhan.com/v1

# Other APIs
NEXT_PUBLIC_QURAN_API_URL=https://api.quran.com/api/v4
```

### 3. Установка зависимостей

```bash
npm install @radix-ui/react-separator @radix-ui/react-select @radix-ui/react-checkbox @radix-ui/react-label class-variance-authority
```

### 4. Запуск приложения

```bash
npm run dev
```

Перейдите по адресу `http://localhost:3000/mosque-finder`

## 🛠️ Технические детали

### Архитектура

1. **Frontend Layer**: React компоненты с TypeScript
2. **Service Layer**: Основная бизнес-логика поиска
3. **API Layer**: Next.js API routes для интеграции с Google Places
4. **Caching Layer**: LocalStorage кэширование с TTL
5. **Fallback Layer**: Локальная база популярных мечетей

### Кэширование

- **Время жизни**: 24 часа для поисковых запросов, 7 дней для деталей
- **Размер**: Автоматическая очистка старых записей
- **Ключи**: Генерируются на основе координат и фильтров

### Лимиты API

- **Дневной лимит**: 100 запросов для экономии квоты
- **Fallback**: При превышении лимита используется локальная база

## 🎨 Компоненты

### MosqueCard
Отображает информацию о мечети:
- Название и адрес
- Рейтинг и отзывы  
- Время пятничного намаза
- Услуги и удобства
- Кнопки действий (маршрут, звонок, сайт)

### MosqueSearch  
Форма поиска с возможностями:
- Текстовый поиск
- Поиск по геолокации
- Фильтры (рейтинг, пятничный намаз)
- Состояния загрузки и ошибок

### MosqueList
Список результатов:
- Skeleton loading
- Empty state
- Сортировка по расстоянию
- Обработка ошибок

## 🔒 Безопасность

- API ключи передаются только через серверные роуты
- Валидация входных параметров
- Rate limiting для предотвращения злоупотреблений
- Безопасное кэширование без чувствительных данных

## 🚨 Troubleshooting

### Проблемы с API

1. **Ошибка 403**: Проверьте API ключ и квоты
2. **Нет результатов**: Проверьте интернет-соединение
3. **Медленный поиск**: Очистите кэш в настройках

### Геолокация не работает

1. Проверьте разрешения браузера
2. Используйте HTTPS для production
3. Fallback на поиск по городу
