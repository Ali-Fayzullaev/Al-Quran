# Muallim Sani PDF Viewer

Современный PDF-просмотрщик с книжным интерфейсом для изучения основ чтения Корана.

## ✨ Особенности

### 📚 Книжный интерфейс
- **Реалистичный дизайн книги** с тенями и эффектами глубины
- **Плавные анимации** перелистывания страниц
- **Адаптивный дизайн** для всех устройств
- **3D эффекты** при наведении на десктопе

### 🎵 Звуковые эффекты
- **Звук переворачивания страниц** (`/flip.mp3`)
- **Настройка громкости** и возможность отключения
- **Автоматическое воспроизведение** при смене страниц

### 📱 Мобильная оптимизация
- **Touch жесты** для навигации (swipe влево/вправо)
- **Оптимизированные контролы** для мобильных устройств
- **Адаптивные размеры** страниц
- **Умное скрытие контролов** с тайм-аутом

### 🚀 Прогрессивная загрузка
- **Быстрый старт** - показ первых страниц за секунды
- **Фоновая загрузка** остальных страниц
- **Индикатор прогресса** с процентами
- **Fallback на демо-контент** при ошибках загрузки

### 🎯 Навигация
- **Галерея страниц** с миниатюрами
- **Клавишные сокращения** (← → для навигации, ESC для выхода)
- **Зоны клика** на странице (левая треть - назад, правая - вперед)
- **Полноэкранный режим**

## 🛠 Архитектура

### Компоненты

- **`PDFBooksIndex`** - Главный индекс выбора книг
- **`PDFViewer`** - Основной компонент просмотрщика
- **`BookViewer`** - Отображение страниц с анимациями
- **`BookControls`** - Панель управления
- **`GalleryView`** - Галерея миниатюр страниц

### Утилиты

- **`PDFLoader`** - Загрузка и конвертация PDF в изображения
  - Поддержка прогрессивной загрузки
  - Обработка ошибок
  - Создание демо-контента

### Маршруты

```
/muallim-sani/               # Главная страница
/muallim-sani/books/         # Индекс книг
/muallim-sani/books/[bookId] # Отдельная книга
```

## 🎮 Управление

### Клавиатура (Десктоп)
- `←` / `→` - Навигация по страницам
- `ESC` - Выход из полноэкранного режима / галереи

### Мышь (Десктоп)
- **Клик по левой трети** страницы - предыдущая страница
- **Клик по правой трети** страницы - следующая страница
- **Клик по центру** - нет действия (предотвращает случайную навигацию)

### Touch жесты (Мобильные)
- **Swipe влево** - следующая страница
- **Swipe вправо** - предыдущая страница
- **Tap по контролам** - управление

### Кнопки
- **🔊/🔇** - Включение/отключение звука
- **⛶** - Полноэкранный режим
- **⊞** - Галерея страниц
- **🏠** - Возврат на главную

## 🎨 Стили и анимации

### CSS классы
```css
.book-container        # 3D контейнер книги
.page-flip-animation   # Анимация переворота
.loading-shimmer       # Эффект загрузки
.gallery-grid          # Сетка галереи
.book-controls         # Панель контролов
```

### Анимации
- **pageFlip** - Переворот страницы (0.6s)
- **shimmer** - Мерцание при загрузке (2s loop)
- **gentleShake** - Легкая встряска для ошибок

## 📱 Адаптивность

### Брейкпоинты
- **Мобильные**: < 768px
- **Планшеты**: 768px - 1024px  
- **Десктоп**: > 1024px
- **Большие экраны**: > 1440px

### Оптимизации
- Разные размеры страниц для разных устройств
- Адаптивные контролы и шрифты

- Умное скрытие элементов интерфейса

## 🚀 Развертывание

1. Поместите PDF файлы в `/public/muallim_sani/`
2. Добавьте `/flip.mp3` в `/public/`
3. Компоненты готовы к использованию

## 📝 Примечания

- **Звуковой файл**: Убедитесь что `/flip.mp3` доступен
- **PDF файлы**: Должны быть в `/public/muallim_sani/`
- **CORS**: PDF файлы должны быть на том же домене
- **Производительность**: Использует прогрессивную загрузку для оптимизации
