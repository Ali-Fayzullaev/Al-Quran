# Google Places Photos API Integration

## Обзор функциональности

Система поиска мечетей теперь поддерживает отображение фотографий из Google Places Photos API. Каждая мечеть может содержать до 5 фотографий, которые отображаются в интерактивной галерее.

## Компоненты

### 1. API Integration (`/app/api/search-mosques/route.ts`)

#### Функция `generatePhotoUrls(photos, apiKey)`
```typescript
function generatePhotoUrls(photos: any[], apiKey: string): string[] {
  if (!photos || photos.length === 0) return [];
  
  return photos.slice(0, 5).map(photo => 
    `https://maps.googleapis.com/maps/api/place/photo?maxwidth=400&photoreference=${photo.photo_reference}&key=${apiKey}`
  );
}
```

**Параметры:**
- `photos` - массив объектов фотографий из Google Places API
- `apiKey` - ключ Google Places API
- Возвращает массив URL для загрузки фотографий (максимум 5)

#### Обновленная функция `transformGooglePlaceToMosque()`
Теперь включает поле `photos` в объект мечети:
```typescript
photos: generatePhotoUrls(details?.photos || place.photos || [], apiKey),
```

### 2. UI Components

#### `MosqueCard.tsx`
- Отображает главную фотографию мечети (первую в массиве)
- При наличии нескольких фотографий показывает счетчик "+N фото"
- При клике на фотографию открывает галерею
- Добавлен hover-эффект с иконкой камеры

**Новые возможности:**
- Интерактивный preview фотографии
- Визуальные индикаторы наличия дополнительных фотографий
- Обработка ошибок загрузки изображений

#### `MosquePhotoGallery.tsx`
Полноэкранная галерея для просмотра всех фотографий мечети.

**Функции:**
- Полноэкранный просмотр фотографий
- Навигация между фотографиями (стрелки, миниатюры)
- Keyboard shortcuts (стрелки влево/вправо)
- Счетчик текущей фотографии
- Адаптивный дизайн

**Управление:**
- Стрелки влево/вправо для навигации
- Клик на миниатюру для быстрого перехода
- Клик вне изображения или кнопка X для закрытия
- ESC для закрытия (планируется)

## API Endpoints

### Google Places Photos API
```
GET https://maps.googleapis.com/maps/api/place/photo
```

**Параметры:**
- `maxwidth`: Максимальная ширина изображения (400px)
- `photoreference`: Референс фотографии из Google Places
- `key`: API ключ

## Производительность

### Оптимизации:
1. **Ленивая загрузка**: Фотографии загружаются только при необходимости
2. **Размер изображений**: Ограничение 400px по ширине для баланса качества/скорости
3. **Количество фотографий**: Максимум 5 фотографий на мечеть
4. **Обработка ошибок**: Fallback изображения при ошибках загрузки

### Кеширование:
- Браузерное кеширование URL изображений
- Переиспользование компонента галереи

## Обработка ошибок

### Сценарии ошибок:
1. **API недоступен**: Возврат пустого массива фотографий
2. **Изображение не загружается**: Замена на placeholder
3. **Отсутствие фотографий**: Скрытие фото-блока

### Fallback изображения:
- Placeholder для недоступных изображений
- Graceful degradation без нарушения UX
