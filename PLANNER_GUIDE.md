# Планировщик изучения Корана - Руководство

## Обзор системы

Комплексная система планирования изучения Корана, работающая полностью на клиентской стороне с использованием localStorage. Позволяет пользователям создавать персонализированные планы обучения, отслеживать прогресс и поддерживать мотивацию без необходимости бэкенда или регистрации.

## Основные компоненты

### 1. Типы данных (lib/plannerTypes.ts)
- **UserProfile**: профиль пользователя с настройками
- **StudyPlan**: план изучения с целями и расписанием  
- **DailyTask**: ежедневные задания
- **ProgressStats**: статистика прогресса
- **Achievement**: система достижений
- **CalendarDay**: календарный просмотр

### 2. Хранилище данных (lib/plannerStore.ts)
- Управление localStorage
- CRUD операции для планов
- Автоматический расчет статистики
- Валидация и целостность данных
- Экспорт/импорт данных

### 3. API расширения (lib/api.ts)
- Интеграция с alquran.cloud API
- Функции для получения сур, джузов, аятов
- Утилиты для планирования
- Рекомендуемые суры для начинающих

### 4. Мотивационная система (lib/motivationSystem.ts)
- Система достижений с различными типами
- Контекстные мотивационные сообщения
- Отслеживание серий и прогресса
- Советы и факты о Коране

## Основные компоненты UI

### 1. Главный дашборд (PlannerDashboard.tsx)
- Обзор активных планов
- Задачи на сегодня
- Общая статистика
- Мотивационные сообщения
- Быстрые действия

### 2. Форма создания плана (CreatePlanForm.tsx)
- Многошаговый мастер создания
- Выбор цели изучения (сура, джуз, весь Коран)
- Настройка расписания и темпа
- Автоматический расчет длительности
- Опции быстрого старта

### 3. Визуализация прогресса (ProgressVisualization.tsx)
- Прогресс-бары для планов
- Общая статистика
- Метрики серий и достижений

### 4. Календарный просмотр (CalendarView.tsx)
- Месячный календарь активности
- Цветовая индикация статуса дней
- Навигация по месяцам
- Детали по клику

### 5. Отображение серий (StreakDisplay.tsx)
- Текущая и лучшая серия
- История активности за 30 дней
- Цели серий с прогрессом
- Мотивационные сообщения

### 6. Система достижений (AchievementSystem.tsx)
- Разблокированные и заблокированные достижения
- Прогресс к следующему достижению
- Уведомления о новых достижениях
- Факты о Коране

## Многоязычная поддержка

Система поддерживает 3 языка:
- **Русский** (основной)
- **Английский**  
- **Узбекский**

Переводы включают:
- Все элементы интерфейса
- Мотивационные сообщения
- Названия достижений
- Советы и подсказки

## Функциональность

### Создание планов
1. Выбор типа цели (одна сура, несколько сур, джуз, весь Коран)
2. Настройка темпа (1-10 аятов в день, 3-7 дней в неделю)
3. Выбор активных дней недели
4. Автоматическое планирование с датами

### Ежедневное использование
- Просмотр задач на сегодня
- Отметка выполнения в один клик
- Возможность пропуска с адаптивным перепланированием
- Запись заметок и времени

### Отслеживание прогресса
- Визуальные индикаторы прогресса
- Отслеживание серий
- Календарный просмотр активности
- Детальная статистика

### Мотивационная система
- Контекстные сообщения поддержки
- Система достижений с различными типами
- Празднование успехов
- Поддержка при пропусках

## Технические особенности

### Хранение данных
- Полностью локальное хранение (localStorage)
- Автоматическое сохранение при каждом действии
- Проверка целостности данных
- Функциональность резервного копирования

### Производительность
- Быстрое извлечение и обновление данных
- Минимальный объем хранилища
- Эффективные расчеты прогресса
- Плавные анимации

### Надежность
- Проверка доступности localStorage
- Механизмы восстановления
- Корректная обработка ошибок
- Валидация данных

## Использование

### Первый запуск
1. Перейти на `/planner`
2. Создать первый план через приветственный экран
3. Выбрать цель и настроить расписание
4. Начать ежедневное изучение

### Ежедневная работа
1. Открыть дашборд планировщика
2. Просмотреть задачи на сегодня
3. Отметить выполненные задания
4. Просмотреть прогресс и статистику

### Расширенные функции
- Создание множественных планов
- Просмотр календарной активности
- Отслеживание достижений
- Экспорт данных для резервного копирования

## Интеграция с приложением

Планировщик интегрирован в основное приложение через:
- Пункт меню в боковой панели
- Использование существующей системы переводов
- Совместимость с темной/светлой темой
- Адаптивный дизайн для всех устройств

Система полностью автономна и не требует внешних зависимостей, кроме API для получения данных Корана.
