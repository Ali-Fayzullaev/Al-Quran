# 🎯 Quick Start Guide - Quran Quiz

## 🚀 Getting Started

### Access the Quiz
Navigate to `/quiz` in your application to start the quiz.

### Configure Your Quiz

1. **Choose Number of Questions**
   - 1 question for quick test
   - 3-5 questions for regular practice
   - 10 questions for comprehensive assessment

2. **Select Difficulty**
   - **Easy**: Famous surahs (Al-Fatiha, last 10 surahs)
   - **Medium**: Well-known surahs
   - **Hard**: Advanced knowledge

3. **Pick Question Types** (at least 1)
   - 📖 Guess the Surah
   - ➡️ Continue the Ayah
   - ✏️ Fill Missing Word
   - 📝 Surah Description

4. **Optional Settings**
   - ⏱️ Enable timer (10-120 seconds per question)
   - 📖 Show English translations

5. **Click "Start Quiz"**

## 🎮 Taking the Quiz

### During the Quiz
- Read the question carefully
- Select your answer from options
- See immediate feedback (correct/incorrect)
- Read explanation and reference
- Click "Next" to continue
- Use "Pause" if you need a break

### Navigation
- ← Previous: Review earlier questions
- → Next: Move to next question
- Progress dots show your position
- Finish: Complete quiz and see results

## 📊 Understanding Results

### Your Score
- **Percentage**: Overall performance
- **Points**: Score out of total possible
- **Correct**: Number of correct answers
- **Time**: Total time and average per question

### Performance Analysis
- Breakdown by question type
- Accuracy percentages
- Time management insights

### Get Better
- Read personalized recommendations
- Review spiritual motivation
- Identify areas to focus on
- Try different difficulty levels

## 💡 Tips for Success

### Study Strategy
1. Start with **Easy** difficulty
2. Focus on familiar surahs
3. Enable translations while learning
4. Review explanations carefully
5. Gradually increase difficulty

### Time Management
- Don't rush on easy questions
- Use timer to practice speed
- Average 30-60 seconds per question
- Pause if you need to think

### Learning from Mistakes
- Read all explanations
- Note which types are hardest
- Review referenced verses
- Retake quizzes to improve

## 🎯 Question Types Explained

### Guess the Surah
- Given: An ayah (verse) in Arabic
- Task: Identify which surah it's from
- Tip: Focus on unique phrases or themes

### Continue the Ayah
- Given: First part of an ayah
- Task: Choose the correct continuation
- Tip: Read the whole verse in your mind

### Fill Missing Word
- Given: Ayah with a blank
- Task: Select the missing word
- Tip: Consider context and meaning

### Surah Description
- Given: Description or fact about a surah
- Task: Identify the correct surah
- Tip: Know surah characteristics
