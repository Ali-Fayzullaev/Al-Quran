# Интеграция системы тем для Mushaf

## Что было сделано

### 1. Объединение систем тем
- Страница Mushaf (`/mushaf`) теперь использует общую систему тем сайта
- Темы синхронизируются между основным интерфейсом и страницей Mushaf
- Настройки в Sheet применяются ко всему сайту, включая Mushaf

### 2. Улучшенная система применения тем
- Добавлена функция `applyMushafTheme()` в `lib/colorThemes.ts`
- Обновлен хук `useColorTheme` для синхронизации тем Mushaf
- CSS переменные автоматически обновляются при смене темы

### 3. Оптимизация для чтения
- Улучшенные цветовые схемы для комфортного чтения
- Специальная обработка темной темы для изображений Корана
- Тема сепия с теплыми оттенками для длительного чтения
- Плавные переходы между темами

## Как использовать

### Смена темы
1. Откройте настройки темы через иконку палитры в любом месте сайта
2. Выберите режим отображения:
   - **Светлый**: Всегда светлая тема
   - **Темный**: Всегда темная тема  
   - **Авто**: Следует системным настройкам

3. Выберите цветовую тему:
   - **Зеленый** (по умолчанию): Успокаивающий зеленый
   - **Изумрудный**: Яркий изумрудный
   - **Синий**: Небесно-голубой
   - **Фиолетовый**: Элегантный фиолетовый
   - **Янтарный**: Теплый янтарный
   - **Розовый**: Нежный розовый
   - **Сепия**: Винтажный теплый оттенок

### Особенности для Mushaf
- Все темы автоматически адаптируются для оптимального чтения
- В темной теме изображения страниц Корана инвертируются для лучшей видимости
- Тема сепия создает эффект старинной книги
- Кнопки и элементы управления имеют полупрозрачный фон для лучшей интеграции

### Файлы, которые были изменены:
- `app/mushaf/page.tsx` - интеграция с системой тем

- `--mushaf-bg` - фон страницы Mushaf
- `--mushaf-page-bg` - фон страниц Корана
- `--mushaf-text` - цвет текста
- `--mushaf-accent` - акцентный цвет
- `--mushaf-border` - цвет границ
- `--mushaf-shadow` - тень элементов

### Классы тем:
- `.theme-light` - светлая тема
- `.theme-dark` - темная тема
- `.theme-sepia` - тема сепии
